## 🌍 Overview

**GRAPHYMA** is a modern, high-impact web platform built to present **Earth Observation (EO)** consulting services, satellite data analytics, user uptake communications, and professional trainings in a clear, accessible, and visually engaging manner.

The platform bridges the gap between complex satellite capabilities (multispectral imagery, SAR analysis, climate metrics) and real-world practical solutions for businesses, public institutions, and international research communities.

---

## ✨ Key Features

* **Interactive 3D Earth & Satellite Visualizer:** Dynamic WebGL/SVG globe showcasing orbiting satellite nodes (ESA, Copernicus, EUMETSAT, JRC).
* **Motion-Driven UX:** Fluid transitions and page animations powered by **Framer Motion**.
* **Dual Theme Engine:** Built-in Light and Dark Mode toggle with persistent cookie state (`graphyma-theme`).
* **Service Detail Workflows:** Step-by-step visual roadmaps for Remote Sensing, User Uptake, and Training services.
* **Interactive Contact & Inquiry Portal:** Tailored service selection form with animated feedback state.
* **Optimized Static Architecture:** Superfast build and lightweight bundle powered by **Vite** and **React**.

---

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** React 19
* **Build Tool:** Vite 8
* **Animation & Motion:** Framer Motion 12
* **Icons:** Lucide React & Custom SVG graphics
* **Routing:** React Router DOM (with scroll state management and smooth route transitions)
* **Styling:** Custom Modular CSS with CSS Variables design tokens
